Code review

A recorded review of Version 1 of the Cloud Security Risk Assessment Tool, made before any enhancement.

If the video does not load, watch it on YouTube.

Before changing any code, I recorded a code review of Version 1 for an audience of peers or a manager. It covers three parts.

  • Existing functionality. A walkthrough of the four pages and the scoring formulas.
  • Code analysis. Weaknesses in structure, security, testing, efficiency and storage. Version 1 had no login, trusted all input, sorted the full table to show five rows and stored everything in a CSV file.
  • Planned enhancements. The fix for each weakness, mapped to the three categories and the five course outcomes.
